## Contract integration note

The UI currently routes data needs through `frontend/src/data/source.ts`, whose functions return `status: 'awaiting'` and empty values. Consequently, most screens listed as partial are scaffolding rather than live contract-backed features. The M0 API has contract endpoints for sites, jobs, flood queries/layers, timelines, impacts, comparisons, validation, exports and GEE, but its own implementation notes say most endpoints still serve contract-example mocks; the onboarding worker stages are placeholders. Frontend integration therefore needs both real API calls and UI handling for the response states and uncertainty objects defined by the handoff contract.
